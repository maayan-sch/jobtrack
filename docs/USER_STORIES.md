# User Stories

1. As a user, I want to create an account, so that I can manage all my job applications.

2. As a user, I want to add, update, and delete job applications, so that I can keep track of my job search.

3. As a user, I want to update the status of each application, so that I know the next step in the application process.

4. As a user, I want to view statistics about my applications, so that I can understand my job search progress.

5. As a user, I want to receive a reminder when I save a job application but have not yet applied, so that I do not forget to submit my application.

## Decision for user story 5

I decided not to include reminders in the first version because the main goal is to build a system for managing job applications and tracking their status. Reminders can be added in a future version.
